REEHAA unifies instance segmentation and multi-condition risk reasoning segmentation for railway environmental hazard analysis in UAV remote sensing imagery.

![REEHAA overview](assets/architecture.png)

## REEH-D Dataset

REEH-D contains **16,708 UAV images** and **128,231 hazard instances** across **six railway lines** and **four provinces**, covering steel-sheet roof buildings, greenhouses, dust-proof nets, and plastic mulch.
